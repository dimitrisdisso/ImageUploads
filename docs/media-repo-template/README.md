# Media files for the Άνω Πόλη news site

Public repository. Everything here is served through jsDelivr and can be downloaded by anyone.

- `images/YYYY/MM/` photos (JPG/WebP/PNG/AVIF, about 1600 px wide)
- `video/YYYY/MM/` short MP4/WebM clips (under 20 MB)
- `audio/YYYY/MM/` MP3/M4A/OGG clips
- `captions/` WebVTT subtitle files (`name.el.vtt`)

Rules: lowercase Latin letters, digits and `-` in file names; never overwrite a published file (upload a new name); one line per file in `CREDITS.md`; only upload what we own or have permission to publish; nothing private (no reader tips, no personal data).
